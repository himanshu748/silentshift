# Contract-first synthetic held-out set

These 48 orders were labelled from their supplied approved contractual evidence before any rule or model evaluation. There are 16 structured, 16 unstructured and 16 clean cases. Every case carries a frozen three-way decision and one-line reason. The prose cases deliberately include stale structured export columns; approved text can change the governing business commitment. The clean cases test unnecessary holds.

The same implementation-aware author wrote the inputs and labels; this is not independent human adjudication, customer evidence, or a representative accuracy estimate. No evaluated system output was used to choose or revise labels. Synthetic approved-source provenance is stipulated by the dataset; SilentShift is not authenticating an email sender.

Labels, reasons, categories, clock and input bytes must not change after evaluation starts. A discovered label concern is reported as a limitation or disputed case without relabelling. Labels/categories/reasons are never copied into the native runtime or model context. The manifest binds the exact scenarios.json bytes. FROZEN.md records the label-first commit and preregistered scoring protocol.
