					55 text An integration accepts an order for  20 CASE . The JSON parses, the required fields are present, and the destination is reachable. The approved contract, however, specifies  240 EA .
				56 text A developer might recognize a plausible explanation: twenty cases of twelve items. That explanation becomes dangerous when the integration treats it as permission. The message contains no approved pack size, and a plausible conversion does not establish what the partner agreed to send.
				57 text SilentShift holds that order before delivery and assembles the evidence an integration operator needs to resolve it. It runs inside an InterSystems IRIS interoperability production, using a native AI Hub agent to investigate and Embedded Python policy to authorize the route. The examples below use synthetic transactions and an IRIS destination simulator.

				96 text An open-ended reference omits the upper bound. Overlapping approved records that disagree produce unresolved evidence; the engine cannot select whichever record makes delivery convenient. An amendment must also have a retrieved approved predecessor with a valid temporal relationship. Matching the current value is insufficient if that lineage is missing.
				97 text Authority is explicit. Reference records come from the server's reference store; message fields cannot promote themselves to approved evidence. Peer records may expose a concern, but even agreeing peers cannot grant release authority.
				98 container
					99 text Representation also belongs to the contract. In the payment example,  12550  minor EUR units and  125.50  major units describe the same numeric amount after a conversion. An interface expecting major units can still receive the wrong representation. SilentShift compares the declared amount and scale using exact decimal values and preserves the original payload. Its normalization helpers do not repair or rewrite a transaction during routing.

					161 text . Automatic delivery requires a resolved comparison to approved evidence, a complete valid recommendation, all required evidence citations, uncertainty at or below  0.35 , and no critical contradiction or duplicate event. The agent must also propose  ALLOW .
